Chop Yew Lee 50th Anniversary

A simple event check-in and table lookup website created for the Chop Yew Lee 50th Anniversary event.

Guests can check in using their phone number, view their assigned table, check the event floor plan and proceed to the next page to scan the hotel's QR code and pay for their parking ticket.

Built With
*HTML
*CSS
*JavaScript
*SVG
Google Sheet as backend.
